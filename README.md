# StateLite

一个用 Swift / AppKit 编写的 macOS 菜单栏监控工具：查看 CPU、内存、温度、网络、风扇和 Clash 状态，在需要时设置风扇目标转速。

当前源码版本 **0.5.0**，要求 **macOS 14 或更高版本、Apple Silicon（arm64）**。这是公开源码项目，**目前未授予开源许可**。应用采用本地 ad-hoc 签名，尚未经过 Apple 公证。

## 下载与安装

从 [GitHub Releases](https://github.com/ARMANDSnow/StateLite/releases) 选择已正式发布的版本，下载 `StateLite-v0.5.0-macos-arm64.zip` 和 `SHA256SUMS`。如果发布页还没有附件，请从源码构建，不要把仓库中的测试记录视为已发布二进制的验收报告。

```sh
# 在存放两个下载文件的目录运行
shasum -a 256 -c SHA256SUMS
ditto -x -k StateLite-v0.5.0-macos-arm64.zip .
```

将 `StateLite.app` 放到 `/Applications`、`~/Applications` 或下载文件夹，打开后点击菜单栏图标。建议选择一个固定位置，更新时退出旧应用再替换；避免同时运行多个副本。系统监控不需要管理员权限，也不会自动安装风扇助手。

遇到 macOS 安全提示，请先确认来源和校验结果，再按系统提供的“隐私与安全性”流程处理。**不要关闭全局 Gatekeeper，也不要从陌生来源获取签名修复命令。** 具体步骤见 [安装说明](docs/INSTALL.md)。

## 日常使用

- 菜单栏最多显示两项指标，可选择并排或上下堆叠。
- 点击指标行展开近期走势和统计；齿轮内可隐藏、排列模块，调整刷新策略。
- 面板默认约 340 × 498pt；展开内容超过高度时滚动。关闭后再次打开返回主页。
- Clash 模块读取本机控制接口的节点信息；“打开 Clash”只打开应用，不切换代理、节点或模式。
- 风扇“自定义”区中的滑块是草稿，点击“应用”才写入硬件。以实际 RPM 和确认消息判断结果，保存的目标值不代表已经生效。

### 风扇首次授权

第一次应用自定义目标时，需要管理员授权安装专用系统助手。同一构建后续调速、退出再打开应用可复用授权；**新构建的代码身份改变时，需要再次授权更新助手**。这不是永不再询问密码的承诺。

每只风扇目标受硬件报告的最低、最高转速限制。自定义控制保持至切回系统、退出或会话结束，没有两分钟上限；退出、睡眠或失联时助手尝试恢复系统控制。重启应用不会自动接管。设置页可确认卸载助手，卸载也需要管理员授权。

固定转速不等同于系统温控曲线。使用前请将其他调速工具切回自动；持续高负载时优先使用系统控制。硬件接口阻塞、强杀助手或断电时，不能保证及时恢复。详见 [安全与权限](docs/SECURITY.md)。

## 读数口径

| 指标 | 含义与限制 |
| --- | --- |
| CPU | 所有核心累计 tick 差值计算的整机繁忙比例；首个样本不可计算 |
| 内存 | 物理总量减实际空闲及可回收缓存，包含系统物理保留区；并非简单的“总量减空闲” |
| 温度 | 已验证机型上 Te05 / Te0S 两路能效核心传感器均值，不代表整颗 CPU 的热点温度；绝对精度未校准 |
| 网络 | 实体 `en*` 接口的入出字节差值，包含代理传输，不叠加 `utun`；32 位累计计数回绕、接口变化会重建基线，极高速多次回绕未覆盖 |
| 风扇 | 实测 RPM；“停转”是读到 0，“—”是不可读；“未接管”仅表示 StateLite 未持有控制 |
| Clash | 规则模式可能按连接分流，显示节点不代表所有流量都使用该节点 |

节能模式下，面板关闭时基础指标约 5 秒、温度约 15 秒采样，打开时约 1 秒 / 5 秒；低电量模式进一步降频。关闭面板且菜单栏不显示温度时跳过温度采样。普通风扇和 Clash 状态主要在面板打开时读取。此策略不等于已经完成新版本功耗验收。

没有遥测上传。Clash 凭证仅在本机运行时使用；手动“检查更新”会请求 GitHub 发布信息，不自动下载、安装或执行新版本。

## 验证状态

**0.4.3 已在一台 Apple M4 Pro 上完成两轮短时实机调速和恢复：**两扇目标 3500 RPM，末两次读数满足目标范围且模式保持手动，之后助手确认系统恢复；第二轮使用新进程复用已安装助手，没有再次请求管理员授权。随后只读检查确认恢复标记清除、助手闲置退出。

0.5.0 已完成本机构建、签名与发行包检查、无硬件回归测试及 25 项更新响应测试。临时预览能打开；新增设置按钮的真实点击验证因测试时锁屏未完成。此前已验证面板、偏好保存、Clash 与风扇 RPM 读取。

**尚未完成：**跨系统重启、真实睡眠／唤醒、实际卸载、异常崩溃恢复、长期连续运行、其他机型和新版本完整功耗对比。Intel Mac 不在当前构建目标内。上述本机结果不代表 GitHub CI、Release 发布或其他电脑均已验收。
