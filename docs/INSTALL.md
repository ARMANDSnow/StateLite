# 安装与排查

## 环境

- macOS 14+，Apple Silicon / arm64。
- 已实测 Apple M4 Pro。其他机型的温度键、风扇数量及控制行为尚未确认。
- 仅查看监控指标无需管理员权限。自定义风扇控制需要管理员批准安装专用助手。

## 从正式发布安装

1. 从 [官方发布页](https://github.com/ARMANDSnow/StateLite/releases) 获取同一版本的 `StateLite-vVERSION-macos-arm64.zip`、`SHA256SUMS`，核对版本及发布说明。草稿不是公开正式发布。
2. 把校验文件与 ZIP 放在同一目录，执行：

   ```sh
   shasum -a 256 -c SHA256SUMS
   ```

   应显示 对应 ZIP 的 `OK`。如果不一致，停止安装并重新下载。SHA-256 用于确认内容完整性；校验文件必须同样来自可信来源，它不代替 Apple 签名、公证或发行者身份认证。
3. 解压：

   ```sh
   # 以 0.5.0 为例，版本号按实际下载修改
   ditto -x -k StateLite-v0.5.0-macos-arm64.zip .
   ```

4. 把应用放到固定位置，例如 `/Applications` 或 `~/Applications`。下载文件夹也可使用。若已运行旧版，先切回系统风扇控制并退出再替换，不要同时启动两份。
5. 打开应用，点击菜单栏图标进入面板。应用没有常规主窗口，不自动设置主应用开机启动。

当前发行采用 ad-hoc 签名，未由 Apple 公证。遇到“无法验证开发者”等提示，请先核对来源、校验值和系统提示；仅在确认信任后使用 macOS“系统设置 → 隐私与安全性”提供的打开选项。没有选项或提示签名损坏时先排查，不要关闭 Gatekeeper、全局清理隔离属性或绕过组织设备策略。

## 风扇助手

第一次点击自定义“应用”会请求管理员授权。安装成功后，同一构建可重复调速；从新进程重新打开应用也可复用授权。升级应用身份后可能需要再次授权。

设置页会显示助手状态：未安装、已安装、需要更新或无法验证。主面板里输入目标只是草稿，只有确认回执才算应用；实际 RPM 可能需要短时间才跟上目标。

助手以 root 身份按需运行，固定文件和通信边界见 [SECURITY.md](SECURITY.md)。不使用调速时不会因打开监控面板而自动安装助手。

## 本机诊断命令

下面以 `/Applications/StateLite.app` 为例。若使用其他位置，只修改 `APP` 这一行；保留路径引号。**必须从完整应用包执行，不能把主程序或助手单独复制出来运行。**

```sh
APP="/Applications/StateLite.app"
codesign --verify --deep --strict "$APP"
"$APP/Contents/MacOS/StateLite" --fan-install-preflight
"$APP/Contents/MacOS/StateLite" --fan-diagnostics
"$APP/Contents/MacOS/StateLite" --snapshot
"$APP/Contents/MacOS/FanHelper" --probe
```

这些命令不设置风扇转速、不安装或卸载系统服务：

| 命令 | 说明 |
| --- | --- |
| `codesign …` | 检查应用包签名完整性，不证明 Apple 公证或发行者可信 |
| `--fan-install-preflight` | 无管理员授权检查实际父进程、签名和系统目录；会创建并清理私有临时副本验证复制后的签名，不写系统安装目录或 SMC |
| `--fan-diagnostics` | 输出最近一次控制状态、助手安装状态和当前风扇读数 |
| `--snapshot` | 输出 CPU、内存、网络和温度快照 |
| `FanHelper --probe` | 仅读取风扇控制元数据，不证明写权限或调速成功 |

`PREFLIGHT_OK` 仅代表这些检查通过，不等同于管理员安装或实际调速成功。分享诊断前自行检查并隐藏个人路径或不希望公开的信息；不要粘贴代理配置文件或 secret。

### 常见情况

- **授权取消：**不会当成调速成功；需要时重新点击应用。
- **需要更新助手：**新构建身份与已安装版本不同，需要一次管理员批准。不要覆盖系统助手文件来绕过身份校验。
- **签名损坏 / resource fork / Finder information：**重新解压可信 ZIP 到非同步目录，并从新副本检查。同步服务或 Finder 元数据可能改变包；不要修改系统安全开关或随意重新签名发行应用。
- **模式或目标写入失败：**将其他调速工具切回自动，查看面板完整诊断和 `--fan-diagnostics`。保存的目标不是生效证明。
- **服务繁忙：**确认没有其他 StateLite 副本正在调速，切回系统并等待会话退出后再试。
- **恢复未确认：**先检查实际 RPM、模式及其他调速工具；不要继续反复应用目标。保留诊断，使用主面板“系统”恢复控制，或按下文设置页卸载流程处理。界面“未接管”不证明其他工具也未接管。

## 可选实机验收：会改变风扇

**以下命令会真实设置风扇，不是只读检查，也不是普通安装的必需步骤。** 仅在明确希望测试时使用；先让其他调速工具处于自动模式，退出其他 StateLite 实例，并保持电脑有人观察。

```sh
APP="/Applications/StateLite.app"
"$APP/Contents/MacOS/StateLite" --fan-verify > fan-verification.jsonl
```

它为全部风扇请求约 3500 RPM（按各自范围限幅），确认后约每 2 秒记录一次，共 6 次，再请求系统恢复。首次安装或版本升级可能弹出管理员授权。末两次实际 RPM、手动模式及目标读回达标，且系统恢复确认后才返回成功。

输出包含实际请求目标；退出码 0 表示该次验收成功，2 表示未持续达到目标但恢复已确认，3 表示恢复请求失败，124 表示 watchdog 超时，其他非零值表示未成功完成。180 秒总 watchdog 与目标确认后 45 秒 watchdog 会断开租约并结束进程；**超时报告的是恢复请求，不能当成恢复已确认**。SMC 调用阻塞、强杀和断电仍有边界。

## 卸载

1. 打开设置 → 风扇助手 → 卸载助手，再次确认并完成管理员授权。
2. 等待卸载结果。控制中的会话须先确认恢复；恢复或卸载失败时保留应用，以便读取诊断和重试。
3. 卸载成功后退出 StateLite，再将 `.app` 移到废纸篓。删除应用不会自动删除系统助手。

若应用已被移除但助手仍在，先从可信来源放回完整应用，使用设置中的卸载入口；更新身份可能需要授权。存在恢复标记或回滚目录时，不要手动删除它们来消除报错。不要执行删除整个 `/Library/PrivilegedHelperTools`、`/Library/LaunchDaemons` 或运行目录的命令；这些位置包含其他软件及系统文件。

实际卸载、跨系统重启与真实故障恢复尚未完成本机验收，出现问题请附版本和脱敏诊断提交 [Issue](https://github.com/ARMANDSnow/StateLite/issues)。
